2 . GATE THE CLAIMS

Mark the one claim that costs the most if it is false (GATE 2). Attach a source to clear a quarantine (GATE 3). Name the one fact that would flip it (GATE 4).

3 . VERDICT

PHUP is the deterministic half: same draft in, same gating out, running entirely on this page with no network. It flags confident-and-unsupported language. It does not verify that an attached source is real, and it cannot tell a true statement from a calm, well-dressed lie. Attached sources are operator-asserted, not PHUP-verified. The hashed receipt proves the report was not altered after sealing; it does not certify the claims. Operator decides. PHUP reports, it does not rule.
